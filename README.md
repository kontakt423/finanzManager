# FinanzManager 💰
**Native Android App · Kotlin + Jetpack Compose · Material Design 3**

Ein vollständiger persönlicher Finanz-Manager mit Split-Topf, MwSt.-Logik und Investmenttracking.

## Features
- 📊 Dashboard mit Hero-Karte & Kontokarten
- 💸 Transaktionen (Einnahme / Ausgabe / Transfer)
- 🔄 Daueraufträge mit automatischer Ausführung
- 🧾 MwSt.-Berechnung (19%) für "Rgnr"-Buchungen
- 👫 Split-Topf (50% oder 100% Partner)
- 📈 Investment-Chart (Canvas)
- ⏱️ Zeitvergleich zwischen 2 beliebigen Daten
- 🌙 Dark Mode (Standard: AN)
- 💾 Room SQLite · JSON Export/Import
- 🔧 WorkManager Background-Worker

## Tech Stack
- **Kotlin** 2.0
- **Jetpack Compose** + Material3
- **Room** Persistence Library
- **DataStore** Preferences
- **WorkManager** (Daueraufträge)
- **ViewModel** + **StateFlow**
